# vGTM — AI-Powered LinkedIn Outreach System

> Automate LinkedIn lead generation with AI-personalized messages,
> follow-up sequences, and auto-proposal generation.

![Next.js](https://img.shields.io/badge/Next.js-000?style=flat&logo=nextdotjs)
![TypeScript](https://img.shields.io/badge/TypeScript-007ACC?style=flat&logo=typescript&logoColor=white)
![Status](https://img.shields.io/badge/Status-Active%20Development-green)

## What this does
- AI generates personalized LinkedIn connection notes per lead
- Automated follow-up sequence (3-step: connect → message → follow-up)
- Admin panel to manage API keys (HeyReach, AI provider, Email)
- Multi-provider AI support: OpenRouter, Gemini, OpenAI

## Tech Stack
Next.js 14 · TypeScript · Supabase · Prisma · HeyReach API · Vercel AI SDK

## Setup
```bash
git clone https://github.com/Awais68/vGTM
cd vGTM
npm install
cp .env.example .env.local
# Fill .env.local with your keys
npm run dev
```
